# Code of conduct

Be kind, specific and constructive.

Project spaces should be welcoming regardless of experience, identity,
background or viewpoint. Harassment, personal attacks, discriminatory language,
doxxing and sustained disruption are not acceptable. Critique code and ideas,
not people; assume good faith while still giving technically honest feedback.

Maintainers may edit or remove contributions and restrict participation when
necessary to protect the community. Serious or sensitive concerns should be
reported privately through the repository's security/contact facilities rather
than litigated in a public issue.
